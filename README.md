# Medições e Contratos

boletins de medição, contratos, painéis e relatórios.

Mora no mesmo projeto Supabase do Roteiros e do Estoque, no schema `medicoes`.
Ver `CLAUDE.md` para as regras e `docs/implantacao.md` para subir o app.
